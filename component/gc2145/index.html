Design notes

  • No JPEG encoder. Outputs YCbCr 4:2:2, RGB565 or raw Bayer, so an ESP32 must JPEG-encode in software and needs PSRAM above QVGA.
  • The active array is 1616×1232, read out as 1600×1200. DVP vs MIPI is selected by register.
