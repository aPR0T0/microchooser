OV7670 VGA DVP camera module

OmniVision camera. A cheap VGA (0.3 MP) sensor with no JPEG, used in many Arduino/STM32/FPGA tutorials. Good for line following or blob tracking at QVGA, but you must buffer raw frames yourself.

Design notes

  • No JPEG engine. A 640×480 RGB565 frame is 600 KB, so most MCUs need PSRAM or have to drop to QQVGA/QVGA.
  • This is a legacy part. For new designs, prefer an OV2640/GC2145-class module on the same 24-pin socket.
  • Pinouts differ between 18-pin header versions (some have RESET/PWDN). Check before wiring.
