AFBR-S50MV85G

Broadcom distance sensor. 32-pixel indirect ToF module (850 nm) for 10 m+ ranging at up to 3 kHz frame rate, usable in 100-200 klx sunlight. Fast 1D/3D distance and motion sensing for outdoor robots; needs a Cortex-M host running Broadcom's driver over SPI.

Design notes

  • No device mapping: it is SPI-only and needs Broadcom's driver library on a Cortex-M host, so it does not fit the I²C multizone ToF device.
  • No processor on the module: an Arm Cortex-M host must run Broadcom's precompiled ToF driver library (API/SDK, github.com/Broadcom/AFBR-S50-API). It needs SPI (pins also usable as GPIO for EEPROM bit-banging), one IRQ GPIO and a dedicated hardware timer for eye-safety timing.
  • Interface is SPI only (3.3 V CMOS, up to 25 MHz), not I²C. Supply 5 V (4.5-5.5 V; 4.75-5.25 V for the full temperature range).
  • Range up to 10 m on 8% black indoors; under 7 m on 8% black at 100 klx sunlight; further on bright targets in dual-frequency mode (<=100 Hz). Unambiguous range 50 m (short-range mode) or 100 m (long-range mode) with dual frequency.
  • 32 pixels (8x4 hexagonal, 1.55° each); receiver FoV 12.4°x5.4°, but the 4°x4° laser beam lights only about 7 (5-16) pixels at a time.
  • Frame rate: 25 Hz is the datasheet's default reference rate; up to 1 kHz with all pixels, 2 kHz with 16 and 3 kHz with 8 pixels (needs SPI >=12-21 MHz).
  • Accuracy ±1% relative, ±10 mm zero-point offset. Precision ~10 mm typ (8% target at 4 m, 25 Hz).
  • 33 mA typical (32 mA sensor + ~1 mA laser), 165 mW active. Operating range -20 to 70 °C.
  • Laser Class 1 only with Broadcom's software configuration and design rules; otherwise it must be treated as Class 3B.
  • Ambient: 100 klx typ, 200 klx max (on a 45% target). Startup/reset is specified up to 100 klx.
