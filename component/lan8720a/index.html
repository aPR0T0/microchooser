Design notes

  • RMII only; the MCU needs an Ethernet MAC
  • Runs from a 25 MHz crystal and can output the 50 MHz REF_CLK to the MAC, or takes an external 50 MHz clock
  • VDDIO 1.62-3.6 V; the 1.2 V core regulator is built in
  • Strap pins are shared with the LED/nINT pins: check the strap pull-ups
  • Energy-detect power-down wakes on link pulses
  • Needs external magnetics or a MagJack
