Design notes

  • Both CAN channels are classic CAN 2.0B only - no CAN-FD.
  • Ethernet MAC needs an external RMII PHY; USB is full-speed device/host/OTG with on-chip PHY.
  • SPI count = 1 legacy SPI + 2 SSP controllers.
  • ROM ISP over UART0 (Flash Magic / lpc21isp); no USB bootloader in ROM (the mbed board uses a separate interface chip).
  • I/O pins are 5 V tolerant. LPC1769 is the pin-compatible 120 MHz version.
  • Mature 2009-era part: expensive per MHz compared to modern Cortex-M4/M33 MCUs; mainly for legacy mbed designs. Also offered in TFBGA100.
