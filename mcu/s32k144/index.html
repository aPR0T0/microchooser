Design notes

  • 3 FlexCAN controllers but only ONE (CAN0) supports CAN-FD; S32K146 has 2 FD, S32K148 has 3 FD.
  • Single 2.7-5.5 V supply: runs directly from 5 V with 5 V I/O.
  • Speed grade: 'H' parts run 80 MHz, 'U' parts 112 MHz in HSRUN (no flash/EEPROM writes or CSEc in HSRUN).
  • Feature letter: 'F' = CAN-FD + FlexIO, 'A' = CAN-FD + FlexIO + CSEc security (AES-128 secure boot/keys). HFT parts have no CSEc.
  • No ROM serial bootloader: a blank chip must be programmed over SWD/JTAG (NXP provides CAN/UART bootloader reference code).
  • FlexRAM can emulate up to 4 KB EEPROM backed by 64 KB D-Flash. LPUARTs support LIN; FlexIO can emulate extra UART/SPI/I2C/I2S.
  • ADC: 2x 12-bit SAR, 16 channels each on the 100-pin package.
