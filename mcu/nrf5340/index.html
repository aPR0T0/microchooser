Design notes

  • Memory figures are for the application core. The network core adds its own 256 KB flash and 64 KB RAM and normally runs the radio stack, with the nRF Connect SDK handling the IPC.
  • The app core has 4 serial boxes, each usable as UARTE, SPIM or TWIM, plus a dedicated 32 MHz SPIM4. So max is 4 UART, 4 I2C or 5 SPI (counts shared). The network core has one more serial box of its own.
  • USB 2.0 Full-Speed is device-only. QSPI runs at up to 96 MHz with XIP and on-the-fly decryption.
  • Running at 64 MHz is more efficient (73 CoreMark/mA vs 66 at 128 MHz). Sleep figure is System ON with the network core RTC running.
  • No ROM bootloader; flash both cores over SWD. Only aQFN94/WLCSP packages, so most hobby PCBs use a module (Raytac MDBT53, u-blox NORA-B1, Ezurio BL5340).
  • No Arduino, MicroPython or CircuitPython port: this is a nRF Connect SDK / Zephyr (or Rust embassy) part.
