Design notes

  • Feature letter after 'EF': E/G = no CAN, F/H = 2x CAN 2.0B, K/M = CAN + crypto engine (AES/3DES/SHA). All have a hardware RNG. CAN is classic 2.0B only (no CAN FD).
  • 252 MHz only with the '-250' speed-grade parts (-40 to 85 C); standard parts are 200 MHz.
  • 64-pin parts: 4 SPI/I2S, 4 I2C, 24 ADC inputs and no EBI. ADC inputs 40/48 on 100/144-pin.
  • USB 2.0 High-Speed OTG with integrated PHY; Ethernet MAC (MII/RMII) needs an external PHY. SQI quad-SPI controller; no SD host controller.
  • Not a low-power part (sleep current ~1.5 mA typical). No ROM bootloader: needs an ICSP/JTAG programmer.
  • Arduino/PlatformIO support only via the legacy, unmaintained chipKIT core (e.g. chipKIT WiFire).
