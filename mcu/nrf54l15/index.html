Design notes

  • No USB and no QSPI peripheral. QSPI is available only as a 'SoftPeripheral' running on the RISC-V (VPR) coprocessor.
  • Five serial interfaces: one high-speed instance (UARTE00/SPIM00 up to 32 MHz, no TWI) plus four shared ones, each UARTE, SPIM or TWIM. So max is 5 UART, 5 SPI or 4 I2C (counts shared).
  • SAADC is 12-bit at 250 ksps, 14-bit at 31.25 ksps or 10-bit at 2 Msps.
  • Sleep figure is System ON idle with GRTC and all 256 KB RAM retained; 0.8 µA in System OFF with GRTC wake-up. About 20 µA/MHz running CoreMark from RRAM.
  • Uses RRAM instead of flash and is supported only by nRF Connect SDK v2.6+ / Zephyr (no legacy nRF5 SDK). Some peripherals are tied to specific GPIO ports (power domains), so check pin assignments.
  • Other packages: QFN40 (24 GPIO), QFN52 (35 GPIO), CSP47 (32 GPIO). Raytac AN54LQ/AN54LV modules exist; Seeed XIAO nRF54L15 is a cheap board.
