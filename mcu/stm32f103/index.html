Design notes

  • USB (device only) and CAN share a 512-byte SRAM and cannot be used at the same time; USB needs a 1.5 kOhm D+ pull-up (many Blue Pills ship with the wrong 10k).
  • No USB DFU in ROM: flash via SWD or the USART1 bootloader (BOOT0), or install a USB bootloader such as STM32duino/HID.
  • C8/CB: 3 USART, 2 SPI (no I2S), no SDIO/DAC; high-density RC/ZE add 2 UARTs, SPI3, 2x I2S, SDIO, 2-channel DAC; FSMC (8080 LCD) only on 100/144-pin.
  • Many cheap boards carry clones/counterfeits (CKS32, CS32, APM32, GD32, CH32F103) instead of genuine ST parts.
