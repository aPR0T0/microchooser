ESP32-C61

Espressif, ESP32-C. Cost-optimised 160 MHz RISC-V Wi-Fi 6 + BLE SoC that adds PSRAM support; a Wi-Fi 6 upgrade path from the ESP32-C3 for memory-hungrier apps.

Design notes

  • No 802.15.4 (Thread/Zigbee) and no CAN, unlike the ESP32-C6; BLE certified to Core 6.0.
  • PSRAM is in-package only (HR2/HR8); HR variants need external flash, HF4 has no PSRAM.
  • USB is the fixed-function Serial/JTAG controller (no HID/MSC); SDIO is slave-only.
  • Arduino-ESP32 supports the C61 only as an ESP-IDF component / custom lib build; MicroPython has no C61 port yet.
  • Needs a 40 MHz crystal.
