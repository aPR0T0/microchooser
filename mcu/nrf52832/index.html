Design notes

  • Serial instances are shared: SPI0/TWI0 and SPI1/TWI1 are the same hardware, SPI2 stands alone. So you get 3 SPI, or 2 I2C + 1 SPI, plus a single UART.
  • Only one UART and no USB. Plan on SWD for flashing and a USB-UART bridge if you need a console.
  • No ROM bootloader. Boards like the Adafruit Feather nRF52832 ship a serial DFU bootloader in flash, but a blank chip needs an SWD programmer.
  • NFC-A tag pins (P0.09/P0.10) are NFC by default. Set CONFIG_NFCT_PINS_AS_GPIOS / UICR to use them as GPIO.
  • Thread/Zigbee/Matter are not officially supported on the nRF52832. Use nRF52833/nRF52840 or newer for those.
  • The 256 KB / 32 KB QFAB variant is cheaper but tight for current nRF Connect SDK builds.
