Design notes

  • Ethernet: Gigabit MAC with an on-chip 10 Mbit PHY; 100M/1G needs an external PHY (RMII/RGMII).
  • USB HS (480 Mbit/s) PHY is on-chip, plus a separate USB FS OTG controller.
  • 256 KB zero-wait flash out of 480 KB total; option bytes can trade flash for up to 128 KB SRAM (e.g. 192 KB flash + 128 KB RAM).
  • FSMC (8080 LCD / external SRAM) only on the LQFP-100 part. DVP camera interface is listed for CH32V307 only.
  • Debug is WCH 2-wire SDI via WCH-LinkE (not ARM SWD). Factory USB/UART ISP bootloader via BOOT0.
