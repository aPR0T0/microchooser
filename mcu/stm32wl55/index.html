Design notes

  • Second core (Cortex-M0+) lets the LoRaWAN stack run separately from the application.
  • Needs a 32 MHz TCXO or crystal and an RF matching network for the high-power (+22 dBm) and/or low-power (+15 dBm) PA outputs.
  • No USB: program over SWD or the UART/SPI ROM bootloader.
  • 2 USART + 1 LPUART, 3x I2C, 2x SPI (one with I2S); AES-256, PKA and TRNG.
