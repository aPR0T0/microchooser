Design notes

  • Crystal versions (-AU/-MU) ship with Atmel's USB DFU bootloader pre-programmed in the boot section (flash, not ROM): flash with dfu-programmer / FLIP without a programmer. The RC-oscillator ATmega32U4RC parts ship blank.
  • The Arduino 'Caterina' bootloader is not pre-installed; burn it via ISP if you want Arduino IDE uploads.
  • 2.5 KB SRAM (ramKB rounds down to 2). USB is device-only (no host); 16 MHz operation needs 4.5-5.5 V (8 MHz at 3.3 V).
  • Needs a 16 MHz (or 8 MHz) crystal and a 1 uF UCAP capacitor for the internal USB regulator.
