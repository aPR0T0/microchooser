Design notes

  • One MCAN controller supporting CAN 2.0 A/B and CAN-FD; needs an external transceiver (an HFXT crystal is advisable for CAN bit timing).
  • ROM bootstrap loader (BSL) over UART or I2C.
  • Analog: 2 simultaneous-sampling 4 Msps ADCs (17 external channels on LQFP-64), 1 Msps 12-bit DAC, 3 comparators, 2 zero-drift op-amps, 1 GPAMP; math accelerator (DIV/SQRT/MAC/TRIG).
  • AES-128/256, TRNG and CRC; RTC with calendar; STANDBY figure is with LFXT and RTC running.
  • Upstream Zephyr board lp_mspm0g3507 exists, but driver coverage is still growing. Rust support (embassy) is not released yet.
  • Cheap WeAct MSPM0G3507 core board (VQFN-32 part) is available for a few dollars.
