Design notes

  • No USB on the WBA5x (the newer WBA6x adds USB OTG HS).
  • +10 dBm max TX power; external PA support; Bluetooth LE Audio (Auracast) capable. ST now also advertises Bluetooth LE 6.0 with recent stacks.
  • Radio stack runs on the same Cortex-M33 as the application (no separate radio core like WB55).
  • 2 USART + 1 LPUART, 2x I2C, 2x SPI, 1x SAI; AES, SAES, PKA, HASH and TrustZone.
  • Needs a 32 MHz HSE crystal; SMPS variants need an external inductor.
