Design notes

  • Only the first 256 KB of flash is zero-wait ('code area'); the rest ('data area') runs much slower, so keep hot code in the first 256 KB.
  • USB is full-speed device only (USBD), no host. 48-pin parts have 3 USARTs, 10 ADC channels and no SDIO; UART3/4 and SDIO need LQFP-64+, EXMC (8080 LCD/SRAM) needs LQFP-100+.
  • Largely pin-compatible with STM32F103; ST HAL/STM32duino code often runs with tweaks (faster clocks, different flash timing). Use GigaDevice's firmware library for full support.
  • ROM bootloader over USART0 (PA9/PA10) via BOOT0; standard Arm SWD/JTAG probes work.
  • 128 KB 'xB' parts (e.g. GD32F303CBT6) have a separate datasheet.
