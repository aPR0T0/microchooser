Design notes

  • Part of the 2024 CH32V002/V004/V005/V006/V007 refresh (QingKe V2C). CH32V002 (16 KB/4 KB) is the ultra-cheap sibling; CH32V005 drops touch keys and TIM3.
  • Stock at LCSC/JLCPCB is still thin (Nov 2026); check availability before committing. TSSOP-20 price is from the JLCPCB parts library.
  • Debug: 1-wire SWIO by default, 2-wire optional; needs a WCH-LinkE. The 3.3 KB BOOT area holds a factory bootloader, but there is no BOOT pin, so plan on a WCH-LinkE for the first flash.
  • Datasheet is Chinese-first; English reference manual is shared with the CH32V00x family. Use MounRiver Studio or ch32v003fun-style toolchains.
  • ADC needs VDD >= 2.4 V. Has an op-amp with 3-way input polling.
