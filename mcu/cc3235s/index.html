Design notes

  • No internal flash: needs an external SPI serial flash (up to 32 MB) holding the file system; the app runs from the 256 KB SRAM. CC3235SF adds 1 MB on-chip flash.
  • No Bluetooth (only coexistence pins for an external 2.4 GHz radio). 802.11a/b/g/n, 2.4 + 5 GHz; peak TX current is about 223 mA.
  • ADC inputs max 1.5 V (pins tolerate 1.8 V); the SD host is 1-bit only.
  • Flashing is done over UART (SOP pins in UARTLOAD mode) with TI UniFlash; debug over JTAG/SWD.
  • Sleep figure is LPDS with 256 KB RAM retained; hibernate (RTC only) is 4.5 µA.
  • Zephyr only supports the CC3235SF variant. CC3235MODS module (CC3235MODSM2MOBR) is certified and includes 4 MB flash and crystals but needs an external antenna (CC3235MODAS has one built in).
