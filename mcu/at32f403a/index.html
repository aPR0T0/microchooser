Design notes

  • Only 256 KB of flash is zero-wait; the rest runs with wait states. SRAM is 96 KB by default, up to 224 KB if zero-wait flash is reduced to 128 KB (user system data).
  • USB is full-speed device only (crystal-less), no host. SPIM maps up to 16 MB of external quad-SPI flash for code/data.
  • 48-pin parts: 7 UARTs, one 4-bit SDIO, no XMC; XMC/8080 LCD interface needs LQFP-64 (8-bit) or LQFP-100.
  • Pin-compatible with STM32F103/GD32F303 footprints but not register-compatible; use Artery's firmware library. Standard Arm SWD/JTAG probes work (AT-Link is Artery's own).
  • ROM bootloader: USB DFU and USART1/USART2 via BOOT0. Deepsleep current is high (~1.3 mA); standby is ~6.5 uA.
