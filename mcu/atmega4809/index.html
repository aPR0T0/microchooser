Design notes

  • Blank chips are flashed over the 1-wire UPDI pin; a USB-serial adapter plus a resistor (SerialUPDI) or any cheap UPDI programmer works.
  • The DIP-40 version uses the 48-pin die with fewer pads bonded (33 I/O); unbonded pins PB[5:0]/PC[7:6] must be configured (pull-up or input-disable).
  • Not register-compatible with the ATmega328P: Arduino code works through the megaAVR core / MegaCoreX, but direct port/register code must be ported.
  • Has an internal 16/20 MHz oscillator, so no crystal is needed.
