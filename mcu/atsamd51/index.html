Design notes

  • No ROM bootloader: blank chips must be flashed once over SWD (e.g. to install an Arduino/UF2 bootloader); afterwards USB uploads work.
  • External QSPI flash is memory-mapped (XIP) in a 16 MB window; 8 KB backup SRAM survives Backup mode.
  • Active current ~65 uA/MHz with the internal buck regulator (~137 uA/MHz on the default LDO).
  • uart/i2c/spi counts are SERCOMs: each SERCOM is either a USART, I2C or SPI, so the totals are shared (e.g. 6 SERCOMs = 3 UART + 2 I2C + 1 SPI). 6 SERCOMs on G/J, 8 on the 100/128-pin N/P parts (not listed here).
  • G (48-pin) parts lose I2S and have 20 ADC inputs; J has 24. PCC = 10-bit parallel capture (camera) on G/J.
  • Crypto: AES, TRNG, public-key accelerator (PUKCC) and SHA via ICM.
