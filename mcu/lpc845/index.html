Design notes

  • Switch matrix: USART/SPI/I2C/SCT functions can be assigned to almost any pin.
  • ROM ISP over USART0 (also I2C/SPI); no USB, so use a USB-UART adapter or SWD.
  • HVQFN33 (JHI33) version has no capacitive touch, only one DAC and 29 GPIO.
  • No RTC - only a self-wake-up timer (WKT). One I2C is Fast-mode Plus on true open-drain pins.
  • LPC845-BRK breakout board has an on-board CMSIS-DAP debug probe and is very cheap.
  • LPC844 is the cut-down sibling (2 USART, 2 I2C, 8 KB SRAM, no DAC/touch).
