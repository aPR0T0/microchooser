Design notes

  • Flexcomm 0-7 are each ONE of USART / SPI / I2C / I2S at a time, Flexcomm 8 is a dedicated high-speed SPI: the per-type counts are not simultaneous (max 9 serial blocks in total).
  • USB1 is high-speed host/device with on-chip HS PHY; USB0 is full-speed host/device with crystal-less device mode. Both can run at the same time.
  • The second Cortex-M33 (CPU1) has no FPU, DSP extension, MPU or TrustZone.
  • ROM ISP over USB0/USB1 (HID class, use blhost / MCUXpresso Secure Provisioning), UART (Flexcomm 0), SPI and I2C - no programmer needed.
  • No QSPI/XIP interface; the top of the 640 KB flash holds the protected flash region (PFR), so slightly less is available to applications.
  • HLQFP100 and HTQFP64 have a 3.4 x 3.4 mm exposed ground pad; KiCad's plain LQFP footprints lack it.
  • Crypto: AES-256, SHA-2, CASPER (ECC/RSA), PUF key storage, PRINCE on-the-fly flash encryption, TRNG, secure boot. PowerQuad DSP accelerator.
  • Rust: lpc55-hal (used by SoloKeys Solo 2 / Nitrokey 3 firmware).
