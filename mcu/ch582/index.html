Design notes

  • BLE only (datasheet: Bluetooth LE 5.0, 2M/1M/Coded PHY, +6 dBm). Needs a 32 MHz crystal; BLE stack is a closed-source WCH library.
  • 448 KB code flash + 32 KB data flash; 32 KB SRAM (30 KB + 2 KB retained in sleep). Built-in DC-DC.
  • CH582F (QFN-28) has 20 GPIO, 8 ADC channels; CH582M (QFN-48) has 40 GPIO. CH583M adds a second SPI.
  • Factory USB/UART ISP bootloader; 2-wire debug (WCH-LinkE) must first be enabled via the ISP tool.
  • 48-pin part has a fine 0.35 mm pitch.
