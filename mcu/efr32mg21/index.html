Design notes

  • Only one package: QFN32 4x4 mm, 20 GPIO. A020 parts have the +20 dBm PA, A010 +10 dBm; 'B' parts add Secure Vault High.
  • Popular as a Zigbee/Thread coordinator or RCP (Home Assistant SkyConnect/ZBT-1, Sonoff ZBDongle-E) running EmberZNet/OpenThread RCP firmware.
  • Sleep current (about 5 µA EM2) is much higher than MG24/BG22, so it's a poor choice for coin-cell end devices.
  • Serial: 3 USART (UART/SPI/I2S) + 2 I2C; 4 timers. No DAC, no PDM, no USB.
  • Matter is set false conservatively: Silicon Labs' Matter SDK targets MG24/MG26 (MG21's 96 KB RAM is tight).
  • No ROM UART bootloader. Flash over SWD; the Gecko Bootloader (UART XMODEM/OTA) is optional and lives in flash.
  • Exposed-pad size isn't listed because the Silicon Labs package drawing couldn't be confirmed.
