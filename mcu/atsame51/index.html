Design notes

  • No ROM bootloader: blank chips must be flashed once over SWD (e.g. to install an Arduino/UF2 bootloader); afterwards USB uploads work.
  • External QSPI flash is memory-mapped (XIP) in a 16 MB window; 8 KB backup SRAM survives Backup mode.
  • Active current ~65 uA/MHz with the internal buck regulator (~137 uA/MHz on the default LDO).
  • CAN-FD (ISO 11898-1:2015) x2 on J/N packages; the 48-pin G package has only one CAN. External CAN transceiver required.
  • uart/i2c/spi counts are SERCOMs: each SERCOM is either a USART, I2C or SPI, so the totals are shared (e.g. 6 SERCOMs = 3 UART + 2 I2C + 1 SPI). 6 SERCOMs on J (64-pin), 8 on N (100-pin).
  • The data sheet table lists 1 SDHC on SAME51N (vs 2 on SAMD51N/SAME54N); treat a second SD host as unavailable.
  • Used on the Adafruit Feather M4 CAN (Arduino + CircuitPython).
