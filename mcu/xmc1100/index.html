XMC1100

Infineon, XMC1000. Cheap 32 MHz Cortex-M0 in a hand-solderable TSSOP-38 that runs from 1.8-5.5 V, with a 12-bit ADC, RTC and two flexible USIC serial channels. A good 8-bit replacement.

Design notes

  • There are two USIC channels (USIC0 CH0/CH1). Each one is UART, SPI (also dual/quad SPI), I2C, I2S or LIN, so the uart/i2c/spi/i2s counts share the same 2 channels.
  • The CPU runs at 32 MHz while peripherals (PCLK) can run at 64 MHz. There is no FPU, MATH coprocessor, CAN, USB or DAC (those come with XMC1300/1400).
  • Only one CCU4 timer unit, so there are just 4 PWM outputs. LED/touch (LEDTS), BCCU and CCU8 are on XMC1200/1300, not the XMC1100.
  • ADC: 12 channels on TSSOP-38/VQFN-40, 8 on VQFN-24 and 6 on TSSOP-16. On TSSOP-38, 8 of the 34 port pins (P2.2-P2.9) are input-only analog/digital.
  • Devices ship in ASC (UART) bootstrap-loader mode via USIC0. Code is loaded to SRAM, so flashing needs a loader tool (e.g. XMC Flasher/DAVE), and the Boot Mode Index (BMI) must then be switched to a user mode. SWD or single-pin SPD debug works too.
  • The 128/200 KB versions (XMC1100-T038X0128/X0200) exist but are rarely stocked. flashKB reflects the 64 KB parts listed.
  • deepSleepUa is the datasheet deep-sleep figure (0.24 mA at 5 V, flash off). There is no hibernate mode, so this is not a coin-cell part.
  • USIC quad-SPI is a protocol mode, not a memory-mapped flash interface, so qspi is false.
  • Arduino support is the XMC-for-Arduino core (KIT_XMC11_BOOT_001 board); the PlatformIO platform is Infineon's infineonxmc.
