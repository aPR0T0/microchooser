Design notes

  • Cortex-M7 at 480 MHz plus Cortex-M4 at 240 MHz sharing the same peripherals.
  • MIPI-DSI host + LTDC; USB OTG_HS (ULPI for 480 Mbit/s) + OTG_FS.
  • Needs SMPS/LDO supply configuration set correctly in firmware; a wrong setting can lock the chip until a special recovery.
  • LQFP176/208 pinouts are not compatible with the single-core H743; TFBGA265 (TFBGA240+25) ballout is mostly compatible.
  • GPIO depends heavily on package: 119 (LQFP176), 148 (LQFP208), 168 (TFBGA265).
