Design notes

  • Blank chips need an ICSP programmer/debugger (PICkit 4/5, MPLAB Snap or ICD); there is no factory bootloader.
  • 64 MHz clock = 16 MIPS. SRAM is 12.8 KB (ramKB rounds down); 1 KB EEPROM; 8-channel DMA.
  • One CAN FD controller (also CAN 2.0B); needs an external CAN FD transceiver.
  • ADC inputs 24/35/43 for 28/40-44/48-pin parts; hardware CVD touch on ADC inputs (mTouch), not a dedicated touch controller.
  • PWM = 4 x 16-bit dual-output PWM (8 outputs) + 3 CCP; also 8 CLC, 3 NCO, 3 CWG. DAC is 8-bit.
  • UARTs support LIN, DMX and DALI in hardware.
