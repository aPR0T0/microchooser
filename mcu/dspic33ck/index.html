Design notes

  • Blank chips need an ICSP programmer/debugger (PICkit 4/5, MPLAB Snap or ICD); there is no factory bootloader.
  • Only the MP50x parts have CAN FD (1 controller); the cheaper dsPIC33CK...MP20x have none. Newer dsPIC33CK512MP60x adds a 2nd CAN FD and 64 KB RAM.
  • 3.0-3.6 V supply only, but many pins are 5 V tolerant. Not a low-power part: sleep current is ~0.4 mA typical.
  • PWM outputs 8/16 (28-pin/48+ pin) high-resolution; ADC inputs 12/19/20/24 for 28/48/64/80 pins; 3 op-amps (2 on 28-pin).
  • The 3 SPI modules double as I2S (shared). 3 x 12-bit DACs feed the comparators; one has a pin output (DACOUT).
