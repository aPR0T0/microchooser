Design notes

  • CAN: 4x Bosch M_CAN (MCAN) controllers, all CAN-FD (up to 8 Mbit/s), plus 4x LIN. All four CAN ports can be pinned out even on the QFN-48. HPM5321 has the same CAN/UART set without the motor-control blocks; HPM5331/HPM5301 have no CAN.
  • USB 2.0 High-Speed OTG with integrated HS PHY. On LQFP-64/QFN-48 USB_DP/DM share pins PA24/PA25 (set them to analog mode for USB).
  • The 1 MB flash is in-package (stacked serial NOR on XPI0) and is the boot device. XPI0 port-A pins are also brought out (datasheet lists Quad SPI NOR/PSRAM/HyperRAM support), but external flash/PSRAM is not counted here.
  • ROM ISP: UART0 on every package, but USB ISP only on the LQFP-100 (LQFP-64/QFN-48 boot ROM is UART0-only). Boot mode set by pins PA02/PA03. Debug is JTAG.
  • No SD/SDIO host, Ethernet or I2S: use SPI for microSD.
  • QFN-48 drops UART4/UART5 and SPI3 (7 UART, 3 SPI); LQFP-64 drops UART4/UART5.
  • Single 3.0-3.6 V supply; on-chip DCDC (needs an inductor) makes the 1.1-1.3 V core rail. IO banks run at 3.3 V or 1.8 V.
  • No battery-backed RTC or 32.768 kHz crystal input (only an internal 32 kHz RC). Shutdown current is about 2.3 uA, but SRAM is not retained.
  • Power: about 33.5 mA from 3.3 V at 480 MHz running CoreMark from ILM with peripherals off (about 60 mA with all peripherals on).
  • Software: HPM SDK (GCC/CMake, free SEGGER Embedded Studio) and RT-Thread BSPs. Not in upstream Zephyr (HPMicro maintains its own fork). The hpm-hal Rust crate (embassy) exists but is marked work-in-progress.
