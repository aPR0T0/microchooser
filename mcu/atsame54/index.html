Design notes

  • No ROM bootloader: blank chips must be flashed once over SWD (e.g. to install an Arduino/UF2 bootloader); afterwards USB uploads work.
  • External QSPI flash is memory-mapped (XIP) in a 16 MB window; 8 KB backup SRAM survives Backup mode.
  • Active current ~65 uA/MHz with the internal buck regulator (~137 uA/MHz on the default LDO).
  • Ethernet MAC (MII/RMII) needs an external PHY (e.g. KSZ8091/LAN8720).
  • SAME54 starts at 100 pins (N = TQFP-100, P = TQFP-128 / 0.4 mm pitch); ADC inputs 28 (N) / 32 (P).
  • uart/i2c/spi counts are SERCOMs: each SERCOM is either a USART, I2C or SPI, so the totals are shared (e.g. 6 SERCOMs = 3 UART + 2 I2C + 1 SPI). 8 SERCOMs on N/P.
  • Popular dev board: SAM E54 Xplained Pro (Zephyr, CircuitPython, Harmony).
