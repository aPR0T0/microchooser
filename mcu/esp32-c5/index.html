Design notes

  • Only Espressif SoC with 5 GHz Wi-Fi (dual-band Wi-Fi 6); BLE is certified to Bluetooth Core 6.0.
  • Two CAN-FD controllers (ISO 11898-1:2015) - need external transceivers.
  • Needs a 48 MHz crystal. ESP32-C5HR8/HR2 have in-package PSRAM only and still need external flash.
  • USB is the fixed-function Serial/JTAG controller (no HID/MSC).
  • PlatformIO support is via the community pioarduino platform.
  • Datasheet EP is 4.7 mm; the nearest KiCad footprint uses a 4.66 mm pad (within tolerance).
