Design notes

  • Dual-band 802.11a/b/g/n (Wi-Fi 4, 2.4 + 5 GHz) and BLE 5.0 sharing one antenna.
  • RTL8720DN has no in-package flash or PSRAM (RTL8720DF adds 4 MB flash, RTL8721DM/RTL8722DM add 4 MB PSRAM); the BW16 module includes external flash.
  • Realtek's selection table lists one USB interface on the RTL8720DN, but BW16 does not break it out and the Arduino SDK doesn't use it - treated as unavailable here.
  • ADC and capacitive-touch share the same 3 pins; KM0 low-power core adds 64 KB SRAM (not counted).
  • Flash over the LOG UART (PA7/PA8) with the Ameba image tool or Arduino upload mode; debug via SWD (PB3/PA27).
  • BW16 exposes 13 GPIO on a 16-pad, 2 mm pitch module; no KiCad library symbol/footprint. No public chip exposed-pad dimension found.
