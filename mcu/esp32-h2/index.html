Design notes

  • No Wi-Fi: Matter-over-Thread end devices need a Thread border router (e.g. ESP32-C6/S3 + H2).
  • Flash is in-package only (2 or 4 MB); the flash pins are not routed out, so no external flash or PSRAM.
  • Needs a 32 MHz crystal. USB is the fixed-function Serial/JTAG controller. Strapping pins GPIO8, GPIO9 and GPIO25.
  • Current datasheet lists the 'S' revisions (ESP32-H2FH2S/FH4S, MINI-1-H2S/H4S); the original FH4 is still widely stocked.
